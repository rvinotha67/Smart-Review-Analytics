# Smart Review Analytics

## About the Project
Smart Review Analytics is a Python-based application that analyzes product reviews and classifies them as Positive, Negative, or Neutral. It helps users understand customer opinions and product feedback.

## Features
- Product review sentiment analysis
- Positive and negative review classification
- Review data visualization
- Word cloud generation
- Interactive analytics dashboard
- Review data processing

## Technologies Used
- Python
- Pandas
- Plotly
- Natural Language Processing (NLP)
- BeautifulSoup
- Dash
- WordCloud

## Project Structure
- `app.py` - Application entry point
- `dashboard.py` - Analytics dashboard
- `scraper.py` - Review scraping
- `sentiment.py` - Sentiment analysis
- `assets/` - Word cloud images
- `data/` - Review datasets

## How to Run
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install the required Python packages.
4. Run the application using the appropriate Python script.

## Project Objective
The objective is to analyze customer feedback and present useful insights that help users understand product reviews more easily.
